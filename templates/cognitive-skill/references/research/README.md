# research/ — 认知调研笔记

## 用途

记录设计该 Cognitive Skill 时对**目标人物 / 思维方法 / 认知框架**的研究。
重点回答：这个心智模型从何而来？凭什么相信它能稳定复现？

## 应该放什么

- **人物画像研究**：当 Skill 模拟某个角色时，对其经历、价值观、表达习惯的整理
- **方法论研究**：领域内成熟思维框架的拆解（如 OODA、第一性原理、SCQA）
- **多源采集对比**：同一概念在不同来源中的表述差异与共识
- **认知模式归纳**：从素材中提炼的稳定模式（如「先质疑前提，再给方案」）

## 命名规则

- 使用 kebab-case
- 推荐前缀：`persona-`、`framework-`、`pattern-`、`crosscheck-`
- 单一主题一文，避免大杂烩

## 示例

```
research/
├── persona-feynman-thinking-style.md   # 费曼的思考风格归纳
├── framework-first-principles.md       # 第一性原理框架拆解
├── pattern-question-before-answer.md   # 「先质疑后回答」模式样本
└── crosscheck-creativity-definition.md # 跨来源对「创造力」的定义对比
```
